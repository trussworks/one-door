# Reviewer and administrator simplification

Written after inspecting the live queue, request record, dashboard and catalog at 1280×720, before reading their implementation for this pass.

## Reviewer queue

1. Which requests need my work or a coordinator?
2. What needs doing next, and which request should I open?
3. How can I narrow or rank the list and return to the same place?

## Reviewer record

1. What is this request, who owns it, and what needs doing next?
2. What did the requester say—including their latest answers?
3. For the review task I am doing, what evidence supports a decision and what must I record?
4. What is still required before first review can finish?
5. How can I resume another task or inspect the record's history without losing unfinished work?

## Catalog

1. Which entries need attention because approval, a review date, or source disagreement is unresolved?
2. What do the original sources say, and which published value are we reviewing?
3. How do I record a supported correction without losing the original evidence?

## Dashboard and reports

1. Which requests or source updates need someone to act?
2. Who should act, and where do I go to do the work?
3. What does each measure count, and which records support it?

## Demo controls

1. What will restoring examples change for other demo visitors?
2. Which requests, unfinished work, ratings, and model costs will remain?
3. Has restoration actually completed, and where can I see the restored examples?
