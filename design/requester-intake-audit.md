# Requester intake: rendered review

September 5, 2026. Scope: the new requester workspace and the added reviewer handoff information, not a recertification of every page in the MVP.

Human design gate: **pending Maz/design review**. Claude independently checked the rendered requester states and the reviewer handoff; that does not substitute for a person's approval. Screen-reader speech and localization were not certified. Maz explicitly excluded mobile design from this pass.

## Evidence

All image references below are in `design/screenshots/intake-three/`.

- `01-start-before.png`: the original starting page at 1440px. `00-feedback-1.png` through `00-feedback-5.png` preserve Maz's cropped live-output screenshots; their original browser viewport is unknown.
- `design/requester-intake-questions.md`: reader questions and the approved flow, recorded before implementation.
- `02-workspace-stripped.png`: the running structure after removing repeated summaries and requester match menus, before the new layout styling.
- `05-start-final.png`, `06-questions-final.png`, `07-refined-1440.png`, `07-refined-1280.png`, `08-refined-text-200.png`, `09-manual-fallback.png`, `10-keyboard-focus.png`: controlled-provider states, real database and production Next build.
- `final-01-questions.png` through `final-05-failed-assistance.png`: Claude's independent check, including requester/reviewer dialogue and undecided service evidence.
- `11-live-provider-first.png`: real Anthropic output in the normal live ledger. The first response failed identifier validation; its automatic retry succeeded. Both attempts count against the same draft's limit. This one case is not a general model-quality certification.

The application uses Source Sans Pro Web. Measured prose was 16.96px with 25.44px line height, page heading 36px, section heading 24px, short status 14px, primary target height 39.25px, and rating targets approximately 55×48px. The final typography batch uses 1.2–1.3 heading line height and 1.5 for multiline input. Input-to-action spacing measured 32px. Desktop width checks and the 200% browser-font check had no document overflow.
